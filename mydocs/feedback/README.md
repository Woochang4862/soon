# 피드백 기록

작업지시자가 AI 의 결과물을 검토하고 **교정한 내용**을 원문에 가깝게 남긴다. 이 폴더는 AI 가 스스로 만들 수 없다. 한 줄 피드백이 설계 방향을 바꾼 경우가 특히 중요하다.

파일명: `<주제>-<NN>.md` (예: `알림-토큰-01.md`). 내용은 짧아도 된다. 지시 원문, 날짜, 어느 타스크에 반영했는지 세 가지면 충분하다.
